  PROJET 01 — Plateforme SaaS de réservation d'infrastructures sportives
────────────────────────────────────────────────────────────────────────────────

TITRE :
SportBook — Plateforme SaaS de réservation sportive

PROBLÈME / SOLUTION :
Un complexe sportif multisites gérait ses réservations via trois tableurs Excel et un carnet de notes. Perte de données, doubles réservations, clients frustrés. Solution : conception d'une plateforme SaaS centralisée avec gestion multi-établissements, planning en temps réel, paiements en ligne et tableau de bord analytique. Les gestionnaires accèdent à toutes leurs infrastructures depuis une seule interface. Les clients réservent 24/7 en 3 clics.

STACK TECHNIQUE :
Laravel 10 • React.js • API REST • MySQL • Bootstrap 5 • Git/Docker

RÉSULTATS :
→ 85% de réduction du temps administratif
→ 0 doublon de réservation depuis la mise en ligne
→ 3 complexes sportifs supplémentaires ont rejoint la plateforme
→ Taux de satisfaction client : 4.8/5


────────────────────────────────────────────────────────────────────────────────
  PROJET 02 — Architecture d'automatisation de contenus multimédias
────────────────────────────────────────────────────────────────────────────────

TITRE :
MediaFlow — Pipeline d'automatisation multimédia tout-en-un

PROBLÈME / SOLUTION :
Un créateur de contenu passait 15 heures par semaine à éditer, reformater et publier ses vidéos sur 5 plateformes (YouTube, Instagram, TikTok, LinkedIn, X). Tâche répétitive, chronophage, source d'erreurs. Solution : mise en place d'un workflow n8n orchestré avec des scripts Python/FFmpeg. Uploader une seule vidéo brute → découpage automatique en clips, génération de sous-titres IA, adaptation aux formats de chaque plateforme, puis publication programmée.

STACK TECHNIQUE :
n8n Workflows • Python • FFmpeg • Prompt Engineering • APIs ChatGPT/Gemini • APIs Social Media

RÉSULTATS :
→ 15h/week → 30min/week de temps de publication
→ ROI temps : 97% de gain
→ +40% de fréquence de publication sans effort supplémentaire
→ Génération automatique de 12 contenus dérivés par vidéo source
